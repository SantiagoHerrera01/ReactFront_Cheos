# Cheos Café - Frontend SPA

Proyecto React + Vite + Tailwind para Cheos Café. SPA que consume backend en VITE_API_URL.

Quick start:

1. Copia el proyecto en tu máquina.
2. Instala dependencias:
   npm install
3. Crea un archivo .env con VITE_API_URL si tu backend está en otra URL.
4. Ejecuta:
   npm run dev
5. Abre la URL que muestre Vite (por defecto http://localhost:5173/)
